# Inventory

Every visual and UX element found in the Tesserae projects, one row per future spec note. Phase 0 result, read from code and docs; the raw per-project tables are in [[Inventory Source tess-ui]], [[Inventory Source tess-shell]], [[Inventory Source Shell Vault]], [[Inventory Source tre]] and [[Inventory Source tess-ui Foundations]] (all in `90 Research`). Rows from the five sources that name the same element are merged here; the Sources column says who defines it.

> [!info] How to read
> - Code status merges the sources: `exists` means every source that lists the element says it is built, `planned` means no source has it built, `partial` means anything in between or a source reports missing parts (reason after the semicolon, taken from the first source that gives one). Shell vault rows describe design intent checked only against code presence, so a `partial` can mean "built in one project, planned in another".
> - Spec note names are provisional: the Plan note fixes the final names when each family is written.
> - MD3 counterpart links point to the official component, style or foundation pages; the links were not opened during Phase 0 and carry `#needs-verification` until [[Open Questions]] item OQ-12 is closed.
> - Raw rows read: 478; merged rows: 276.
