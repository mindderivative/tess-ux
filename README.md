# tess-ux

The UX source of truth for every Tesserae project that draws visual elements: applications, user interfaces, shells, desktop environments and dashboards.

- **UX Design Specification**: generalised principles, foundations, tokens, interaction rules, accessibility, states and patterns.
- **UX Component Design Specification**: one specific specification for every widget, module, block, surface, frame, tooltip, overlay and popup.

Foundation: Material Design 3 is the baseline reference. Every Tesserae departure from it is recorded with its reason.

This repository is an [Obsidian](https://obsidian.md) vault. Open the folder in Obsidian, or read the Markdown notes directly. Start at `00 Home/Home.md`.

Status: the vault was created on 2026-11-21; the specifications are in progress.
